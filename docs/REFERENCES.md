# 参考资料

## 直接灵感来源

### Bilibili：BV1TNaP6MEUJ

这是 StyleForge 的直接灵感来源之一。

视频带来的核心启发是：

```text
优秀网站
→ AI 分析 UI
→ 提取设计知识
→ 沉淀知识库
→ 再让 AI 使用这些知识完成设计
```

StyleForge 在此基础上的扩展是：

- 不只追求模仿；
- 不只收集 Prompt；
- 把案例作为设计学习材料；
- 区分客观观察与个人偏好；
- 最终形成 Personal UI Style System；
- 让 AI 负责分析和执行，而不是最终审美决策。
